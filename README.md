# 🌿 AIoT Learning Lab (CN466)

ยินดีต้อนรับสู่เว็บไซต์เรียนรู้โครงงาน **AIoT (Artificial Intelligence of Things)** สำหรับโครงงานวัดอุณหภูมิและความชื้น พร้อมระบบวิเคราะห์สภาพอากาศและแจ้งเตือนผ่าน Telegram!

## 🎯 ภาพรวมโปรเจกต์
เว็บไซต์นี้จัดทำขึ้นเพื่อเป็นคู่มือและสื่อการสอนแบบ Step-by-Step ให้ผู้เรียนสามารถสร้างระบบ IoT ที่ฉลาดขึ้นด้วย AI ได้ด้วยตนเอง โดยแบ่งสถาปัตยกรรมออกเป็น 3 ส่วนหลัก:
1. **Hardware (IoT):** ใช้บอร์ด **Cucumber (ESP32-S2-Saola-1)** อ่านค่าเซนเซอร์สิ่งแวดล้อม
2. **AI & Logic:** ประมวลผลและจำแนกสถานะอากาศด้วย Python / Google Colab
3. **UI & Notification:** แจ้งเตือนผลและโต้ตอบผ่าน **Telegram Bot**
