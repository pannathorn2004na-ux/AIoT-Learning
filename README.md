# 🌿 AIoT Learning Lab (CN466)

ยินดีต้อนรับสู่เว็บไซต์เรียนรู้โครงงาน **AIoT (Artificial Intelligence of Things)** สำหรับโครงงานวัดอุณหภูมิและความชื้น พร้อมระบบวิเคราะห์สภาพอากาศและแจ้งเตือนผ่าน Telegram!

## 🎯 ภาพรวมโปรเจกต์
เว็บไซต์นี้จัดทำขึ้นเพื่อเป็นคู่มือและสื่อการเรียนรู้แบบ Step-by-Step ช่วยให้ผู้เรียนเข้าใจหลักการทำงานของเทคโนโลยี IoT การรับส่งข้อมูล การประมวลผลด้วย Python และการประยุกต์ใช้ร่วมกับระบบแจ้งเตือน โดยใช้ตัวอย่างโครงงานตรวจวัดอุณหภูมิและความชื้น ซึ่งแบ่งการทำงานออกเป็น 3 ส่วนหลัก ดังนี้
1. **Hardware (IoT):** ใช้บอร์ด **Cucumber (ESP32-S2-Saola-1)** ร่วมกับเซนเซอร์สำหรับตรวจวัดอุณหภูมิและความชื้น
2. **Data Processing & Logic:** ใช้ **Python บน Google Colab** รับข้อมูลผ่าน **MQTT** และประมวลผลเพื่อตรวจสอบสถานะอุณหภูมิตามเงื่อนไขที่กำหนด
3. **UI & Notification:** ใช้ **Telegram Bot** สำหรับแจ้งเตือนสถานะและโต้ตอบเพื่อสอบถามข้อมูลการตรวจวัด
